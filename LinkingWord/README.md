# LinkingWord

Use the shared Chrome extension in `../chrome/` and assign **LinkingWord** to its Discord channel. The next word must begin with the last letter of the previous accepted word. The panel removes accepted words and words the bot rejects as already linked from its available candidates. When the bot resets the game, click **Reset game words** after the reset message appears. This clears the saved used-word list and ignores earlier visible messages, so those words can be suggested again in the new game. The bot may use a different dictionary. The helper never posts a word.
