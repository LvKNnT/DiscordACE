# Wordle

Use the shared Chrome extension in `../chrome/` and assign **Wordle** to its Discord channel. The panel reads the bot's five-square guess feedback, including the first grid after a new-round message, filters five-letter candidates, and warns when your configured display name made the last accepted guess. If clue colors are not readable, enter each guess in the current round with five `B`, `Y`, or `G` colors (`B` = gray/black, `Y` = yellow, `G` = green). Manual clues take precedence over the parsed grid until cleared. It never posts a guess.
