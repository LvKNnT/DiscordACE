# CountNum

Use the shared Chrome extension in `../chrome/` and assign **CountNum** to its Discord channel. The panel follows confirmed numeric messages and Sabi reset messages, shows the next number, and warns when your configured display name made the last accepted move. In the popup, **Auto-type next number** can fill an empty Discord composer after another player's confirmed move. It never sends a number and will not overwrite a draft or type when the turn is uncertain.
